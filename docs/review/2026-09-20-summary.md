# NowTutors code review: summary

Reviewed 2026-09-20, `main` at 9775408. Read-only: no file in `src/`, `drizzle/` or `tests/` was changed, nothing was run against a database, and no finding here was executed. Everything marked confirmed was confirmed by reading the code and migrations. Pass files in this folder carry the detail and the full "what held up" notes.

The application layer is careful. Every server action authorizes from the session, every money mutation goes through `lib/credits/ledger.ts`, every state transition is a conditional UPDATE or lock-then-check, and the two-client database setup is wired correctly. The serious problems sit in two places the app layer cannot see: the database's own permissions (what a signed-in user can do by calling Supabase's REST API directly, skipping the app), and one gap between two phases of the build (who writes a tutor's earnings).

Out of scope and not reported: all Phase 10 items, reviews, SPEC 14, visual design, micro-performance.
